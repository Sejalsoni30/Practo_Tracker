# Practo Appointment & Patient Follow-up Tracker

A full-stack web application designed to manage doctor appointments, patient medical logs, and automated post-consultation follow-up tracking.

## Tech Stack
* **Frontend**: React, Vite, React Router, Axios
* **Backend**: Node.js, Express.js
* **Database**: MongoDB, Mongoose
* **Authentication**: JSON Web Tokens (JWT), Bcrypt.js
